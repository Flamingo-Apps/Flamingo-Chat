# Security Policy

Flamingo Chat handles private conversations and account details for real students. Security reports are taken seriously and are welcome.

## Reporting a vulnerability

**Do not open a public issue, pull request or discussion for a security problem.** A public report puts users at risk before a fix exists.

Report it privately through GitHub:

1. Open the repository's **Security and quality** tab.
2. Click **Report a vulnerability**.
3. Fill in the form and submit it.

Please include:

- what the problem is and which part of the system it affects;
- the steps to reproduce it, or a proof of concept;
- what an attacker could do with it;
- any fix you would suggest.

## What to expect

This project has one maintainer. Reports are read as soon as possible, but there is no guaranteed response time. You will be told whether the report is accepted, and you will be credited in the fix unless you ask not to be.

## Scope

In scope:

- the code in this repository;
- the deployed application, once it is launched.

When testing the deployed application:

- use only accounts you created yourself;
- do not read, change or delete other people's messages or account data;
- do not run denial-of-service tests or automated scans that degrade the service;
- do not use social engineering against users or the maintainer.

## Supported versions

The project has no releases yet. Fixes are made on the `main` branch only.
